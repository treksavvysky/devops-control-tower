The DCT action button; use semantic variants only for their meaning (success = approve, danger = reject).

```jsx
<Button icon="play">Run task</Button>
<Button variant="success" icon="check">Approve</Button>
<Button variant="danger" icon="x">Reject</Button>
<Button variant="secondary">View evidence</Button>
<Button variant="ghost" size="sm">Cancel</Button>
```

Sizes: sm / md / lg. Gradient variants glow faintly on hover; nothing bounces.
